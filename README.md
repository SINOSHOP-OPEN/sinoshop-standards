# SINOSHOP Coding Standards Specification System

**Physical Entity · Document · Sensor Encoding Specifications**

> Standardization is the cornerstone of digital twins. This system provides unified encoding and metadata specifications for all 14 core asset systems of SINOSHOP, ensuring full traceability, auditability, and interoperability from physical entities to digital assets.

---

## 📌 System Positioning

This specification system is a supporting standard for the **SINOSHOP V3.0 Technical Framework**, providing encoding and data governance support for:

- 🌊 **14 Core Asset Systems** (001–014)
- 🧱 **Foundation Process Modules** (Thin Shell/Thick Plate/M18 Units)
- ⚡ **Energy Link Closed Loop** (Generation-Storage-Consumption Chain)
- 📊 **FreeCAD Digital Twin Framework** (Parametric Console/BIM Attributes)

## 📂 Core Content

| Specification Module | Description | Associated Systems |
| :--- | :--- | :--- |
| **Physical Entity Encoding** | Assigns unique identifiers to physical entities such as floating bodies, tunnels, ships, and ports | 001–014 |
| **Document Encoding** | Standardizes numbering and version management for technical documents, white papers, and drawings | All subsystems |
| **Sensor & Data Point Encoding** | Unifies naming conventions for sensors and data points | 002/004/006/007/013/014 |
| **Digital Twin Entity Association Rules** | Defines mapping relationships between physical entities and digital twin models | FreeCAD Framework → All |
| **CMDB Extended Attribute Templates** | Extended attribute standards for Configuration Management Database | 011 Asset Soul |
| **Water Anchor Hammer Sensor Encoding Supplement** | Specialized sensor encoding for the 004 system water anchor hammer | 004 |
